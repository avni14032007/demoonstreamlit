# 🤖 Streamlit ChatBot

A simple rule-based chatbot built with Python and Streamlit.

## Features
- Greetings (hi, hello, hey, namaste)
- Remembers your name ("my name is ___")
- Current time and date
- Jokes, fun facts, motivational quotes
- Random number, coin toss, dice roll
- Calculator (e.g. `2+3*4`)
- Typing indicator, clear-chat button, help sidebar

## Run locally
```bash
pip install -r requirements.txt
streamlit run chatbot.py
```

## Tech
Python · Streamlit · NumPy
